The fixed user contract is represented in [parity.json](parity.json). Its per-tool documented modes and Free-account eligibility still require review; the recorded mode targets are not an exhaustive audited baseline. [baseline-sources.json](baseline-sources.json) retains hashes, retrieval dates and linked official documentation for the initial index sources. Do not silently expand the October 9 scope with newer tools. Do not mark partial implementations complete.

Current workflow limitations are explicit in the interface. Sketches are anchored numeric rectangle/circle profiles. Fillets/chamfers affect all edges. Each part must remain one connected solid; a disconnected boolean result fails instead of receiving a misleading single-part identity. Feature references are stable IDs; display face indexes are not persistent references. Regeneration rebuilds the full model. STEP/STL export is implemented; STEP import is a kernel test only. No IGES/OBJ/DXF/SVG or PDF exchange is implemented.

Verification is recorded in [verification.json](verification.json) after final tests. The additional test/repair rounds and findings are recorded in [VALIDATION.md](VALIDATION.md). The automated suite checks exact analytic dimensions/area/volume/topology, scale tolerance, solver DOF/conflicts/redundancy, downstream edits, invalid history, STEP self-roundtrip, independently computed ASCII STL volume, project validation, ZIP size limits, transaction rollback on quota/interruption, and worker cancel/crash/timeout. Browser workflows exercise the built artifact, actual bracket construction, edits, undo/redo, export, project opening, reload recovery, failure preservation, visible storage failures, imperial numeric input, and mobile drawers. These are checkpoint tests, not the complete parity acceptance suite.

The Linux Mint test host initially lacked WebKit's `libavif16` and related libraries, and headless Firefox could not render WebGL. Browser tests use software rendering with Xvfb; missing packages were extracted into a temporary directory/browser cache without changing system packages. CI installs official Playwright dependencies. **Physical iOS Safari and Android Chrome have not been tested. Emulation does not satisfy that gate.**
