# Functional parity register

Target: Onshape built-in Free CAD workflows on October 9, 2026. The user contract is fixed. The linked-document mode/Free-eligibility audit is **unfinished**; `baselineFrozen` must stay false until reviewed. This register does not claim completed parity.

The machine-readable source is [parity.json](parity.json). Each row has mode targets, a reproducible workflow, a reserved acceptance ID, evidence, and implementation scope. Reserved test IDs are planned tests, not executable or passing tests. Do not mark a row complete until every audited mode and acceptance check has executable passing evidence.
